# E935 (European 2.0 16V) notes

E935 is the ROM ID of the European 1G Eclipse 2.0 16V non-turbo ECU
(MMC MD169144, MEC E2T36583). The same ECU is reported in the Galant E33 GTi 16V.
No public EPROM dump or disassembly exists as far as we know, so the address
map below is unverified. This page collects what we find.

## Hardware observations

| Item | Observed | Car |
|---|---|---|
| Diagnostic pin 1, idle | ~12 V | 1991 Eclipse GS, Swiss spec |
| Diagnostic pin 10, ignition on | ~12 V (pulled up through the ECU) | 1991 Eclipse GS, Swiss spec |
| Populated connector pins | 1, 5, 6, 10, 11, 12 | 1991 Eclipse GS, Swiss spec |
